# Fact-gap candidates (the "Fact gaps" section of check run --fact-gaps; read by fact_gaps() in readyasu_diff.py).
# Finds sentences of the final draft that may give only a metaphor or a degree word and no content or value. The list is partial.
# Format: one "kind<TAB>regular expression" per line. Kinds:
#   reference  refers to a value it does not give (before the deadline, as discussed)
#   figure  a metaphor hides the content (lays the groundwork, paves the way, breathes new life into)
#   effect  only an effect, not what changed (improves reliability, reduces friction)
#   degree  only a degree word, not how much (significantly, dramatically)
#   change  a change without the before and after values (shortened, sped up)
# Each sentence reports the kind of the first matching line, so the order matters.
# Sentences with a digit, a hedge or plan word, a vague quantity (some, several, a few), a closing resolution,
# questions, headings, table rows, code and quotations are never reported (rules inside readyasu_diff.py).
# The section is not shown for --doc-type essay or promo. Matching ignores case.
# If this file is missing or has an error, the built-in copy of this list is used and the section says so.
